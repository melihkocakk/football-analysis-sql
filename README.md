# ⚽ Football League SQL Analysis

A MySQL project analyzing football league data through 7 different analytical queries.

## 📁 Database Schema
- **teams** - Club information
- **players** - Player details
- **matches** - Match results
- **goals** - Goal records with minute and player info

## 🔍 Analyses
1. Top scorers in the league
2. League standings table (points, wins, draws, losses)
3. Top scorer ranking within each team
4. Most goals conceded by team
5. Goals by match period (Early / Middle / Late)
6. Highest scoring matches
7. Players with no goals (LEFT JOIN)

## 🛠️ SQL Concepts Used
- JOIN, LEFT JOIN, Multiple JOINs
- GROUP BY, HAVING
- CASE WHEN
- UNION ALL
- CTE (WITH)
- Window Functions (RANK, PARTITION BY)
- Subqueries

## 🗄️ Tools
- MySQL 8.0
- MySQL Workbench
